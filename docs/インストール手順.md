# KantanZip のインストール手順

社内向けツールです。以下の手順でインストールしてください。
所要時間は5分ほどで、**この作業が必要なのは最初の1回だけ**です。

---

## 1. アプリを取り出す

1. 配布された `KantanZip.dmg` をダブルクリックします
2. 開いたウィンドウの中で、**KantanZip** のアイコンを
   **アプリケーション** フォルダのアイコンにドラッグします
3. ドラッグが終わったら、開いたウィンドウは閉じてかまいません

## 2. 最初の1回だけ、起動の許可をする

このアプリは社内で作ったもので、Apple の審査を受けていません。
そのため最初に開こうとすると、macOS が念のため確認を求めてきます。

1. アプリケーションフォルダの **KantanZip** をダブルクリックします
2. 「開けません」という内容の警告が出ます。**「完了」または「OK」を押して閉じます**
   （ここで諦めないでください。次の手順で許可します）
3. 画面左上の **アップルメニュー** →**システム設定** を開きます
4. 左側のリストから **プライバシーとセキュリティ** を選びます
5. 右側を下までスクロールすると、**セキュリティ** の項目に
   「"KantanZip" は開発元を確認できないため、使用がブロックされました」
   のような文章が出ています
6. その横の **「このまま開く」** ボタンを押します
7. 確認のダイアログが出たら、もう一度 **「開く」** を押します
8. **Mac のログインパスワード** を入力します

これで起動します。**2回目以降はダブルクリックするだけで開きます。**

---

## 使い方

1. KantanZip を起動します
2. 圧縮したいファイルやフォルダを、ウィンドウにドラッグ&ドロップします
   （「ファイルを選択…」ボタンからでも選べます）
3. パスワードを付けたい場合は「パスワードを付ける」をオンにして入力します
4. 自動的に圧縮が始まり、**元のファイルと同じ場所に zip ができます**

### パスワードについて

- 既定のままなら、**受け取った相手はダブルクリックでそのまま開けます**
  （パスワードの入力を求められます）
- 「強力な暗号化を使う」をオンにすると安全性は上がりますが、
  **相手が 7-Zip や Keka といったアプリを持っていないと開けません。**
  相手の環境が分からないときはオフのままにしてください
- **パスワードは zip とは別の手段で伝えてください**（電話、チャットなど）。
  同じメールに zip とパスワードを両方書くと意味がなくなります

---

## 困ったときは

**「アプリが壊れているため開けません」と出る**
ダウンロードが途中で失敗している可能性があります。
`KantanZip.dmg` をもう一度ダウンロードし直してください。

**警告が出るのは大丈夫なのか**
社内で作ったアプリで、Apple への登録（有料）をしていないために出る警告です。
**ただし、この手順書に書かれていないアプリで同じ警告が出た場合は、
許可せずに情報システム担当に相談してください。**
「警告が出たら許可する」を習慣にしないようお願いします。
