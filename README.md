# KantanZip

macOS用のかんたんzip圧縮アプリ。ファイルやフォルダをウィンドウにドロップするだけで、
パスワード付きzipを作成できます。社内の非IT技術者向けに作られています。

## 機能

- ドラッグ&ドロップまたはファイル選択ダイアログで圧縮
- 複数ファイル・フォルダをまとめて1つのzipに
- パスワード付きzip
  - **ZipCrypto（既定）**: 受け取った人がダブルクリックでそのまま開ける
  - **AES-256**: 強力だが、開く側に7-ZipやKekaなどが必要
- **パスワードの自動生成**（生成と同時にクリップボードへコピー）
- **履歴**: どのファイルにどのパスワードを付けたかを後から確認できる
- 圧縮中の進捗表示
- 出力先は元ファイルと同じ場所（同名があれば `名前 2.zip` と連番）
  - 複数ファイルをまとめるときは、名前が自明でないため保存ダイアログで確認
  - 設定で単一ファイルのときもダイアログを出せる

### パスワードの保存について

履歴から後でパスワードを確認できますが、**パスワード本体はmacOSのキーチェーンに
保存**しており、履歴ファイル（JSON）には一切書き込みません。
履歴は100件を上限とし、溢れた分はパスワードごと削除されます。

パスワードを残したくない場合は、履歴画面の「すべて削除」でキーチェーンからも消せます。

## 動作環境

- macOS 13 Ventura 以降（Intel / Apple Silicon 両対応）

## 開発

```sh
scripts/fetch-7zz.sh   # 同梱する7zzを取得（初回のみ）
swift test             # テスト実行
swift run              # 開発中の起動

scripts/make-dmg.sh    # build/KantanZip.dmg を作成
```

構成の詳細と開発計画は [plan.md](plan.md) を参照。

## 配布方法

**現在の方針: Google Drive で配り、受け取る人に初回だけ起動を許可してもらう。**

macOSのGatekeeperは **`com.apple.quarantine`（隔離）属性が付いたファイルにだけ** 働きます。
ブラウザでダウンロードすると必ずこの属性が付くため、Apple の有料審査を受けていない
アプリは初回だけ許可の操作が必要になります。

### 配布の手順

```sh
scripts/fetch-7zz.sh   # 初回のみ
scripts/make-app.sh
scripts/make-dmg.sh
```

できあがった `build/KantanZip.dmg` と、
**[docs/インストール手順.md](docs/インストール手順.md) を必ずセットで** Google Drive に置いてください。
手順書がないと、受け取った人は「開けません」の警告で詰まります。

### 受け取る人の作業

初回のみ、5分ほどの操作が必要です。

1. dmg をダウンロードしてダブルクリックし、アプリをアプリケーションフォルダにドラッグ
2. 一度ダブルクリックして警告を出す（この操作をしないと次の項目が現れません）
3. システム設定 → プライバシーとセキュリティ → 一番下の「このまま開く」→ ログインパスワード

2回目以降はダブルクリックで起動します。
**アプリを更新した場合は、その版で1回だけ再度この許可が必要**になります。

### 他の選択肢

| 方法 | 費用 | 受け取る人の手間 | Google Drive |
|---|---|---|---|
| **初回だけシステム設定で許可**（採用中） | 無料 | 初回5分（版ごと） | 使える |
| 社内共有フォルダ / USB で配布 | 無料 | なし | 使わない |
| MDM で配布 | 既存契約なら追加なし | なし | 不要 |
| Developer ID署名 + 公証 | $99/年 | なし | 使える |

配布人数が増えたり更新が頻繁になったりして、
「5分 × 人数 × 版数」が割に合わなくなったら公証への切り替えを検討してください。
そのためのスクリプトは用意済みです。

```sh
CODESIGN_ID="Developer ID Application: NAME (TEAMID)" scripts/make-app.sh
scripts/make-dmg.sh
NOTARY_PROFILE=kantanzip scripts/notarize.sh
```

初回の準備手順は [scripts/notarize.sh](scripts/notarize.sh) の冒頭コメントを参照。

### 配布経路と隔離属性の対応

| 配布経路 | 隔離属性 | 未署名アプリの起動 |
|---|---|---|
| Google Drive（ブラウザでダウンロード） | 付く | 初回のみ許可操作が必要 |
| メール添付・AirDrop・Slack等 | 付く | 初回のみ許可操作が必要 |
| 社内ファイルサーバー（SMB共有）からコピー | 付かない | そのまま起動する |
| USBメモリ・外付けディスク | 付かない | そのまま起動する |

## セキュリティ上の注意

- **ZipCrypto は互換性を優先した弱い暗号方式です。** 総当たり攻撃に耐える強度はありません。
  本当に守りたいデータには AES-256 を選ぶか、暗号化ディスクイメージなど別の手段を使ってください。
- 隔離属性を手動で剥がす方法（`xattr -dr com.apple.quarantine`）をユーザーに教えるのは
  避けてください。「警告が出たらこのスクリプトを実行する」という習慣は、本物のマルウェアを
  実行させる手口とまったく同じ形をしています。
  なお macOS 26 で検証したところ、**そもそもこの方法は現在では通用しません。**
  Gatekeeperが一度ブロックすると `com.apple.provenance` 属性が付与され、
  これがSIPで保護されているため `xattr -d` が
  `Operation not permitted` で失敗します。
  素直にシステム設定から許可するのが唯一の正規手順です。

- 配布元: https://www.7-zip.org/
- ライセンス全文: アプリバンドル内 `Contents/Resources/7zz-License.txt`、
